# 第四部分 视频生成

一段视频可以只有几秒钟，却包含图像生成中很少单独面对的问题。人物转身时，脸部逐渐离开视野，衣服和身体的背面开始出现；相机越过一根柱子，被遮住的背景需要重新露出。画面中的每个局部都在变化，又受到此前内容的约束。

这些约束来自不同地方。有些可以在图片中直接观察，有些由姿态、轨迹和声音规定，还有一些只能从前面的画面或镜头中查找。视频模型的设计，很大程度上取决于如何组织这些观测和条件，以及如何处理仍然缺少信息的部分。

## 从照片生成漫游视频

假设给出一张建筑照片，希望相机缓慢向前移动。起始画面已经确定，接下来的视差、遮挡和新出现的区域仍需要生成。近处的栏杆应该比远处的屋顶变化得更快，建筑上的直线应当随投影改变，而房屋结构应当保持。

图生视频模型可以从图片中提取外观和布局，再结合文字或相机条件产生运动。第16章先解释图片与视频怎样进入编码器，第17章介绍这些条件如何进入生成网络，第18章进一步讨论相机、深度与轨迹。

多张照片会提供更多观测，也带来对应关系的问题。照片是否拍摄同一座建筑，视角之间有多少重叠，拍摄期间有没有行人经过，都会影响它们能否共同约束一条相机路径。将照片作为参考输入，与根据照片恢复空间几何，对数据的要求和结果的含义都有区别。第五部分还会继续介绍相机估计、多视图重建和三维表示。

如果输入来自几个不同的地点，视频可以通过镜头切换组织它们。此时需要安排镜头顺序、画面风格和转场，技术问题也就从单个场景的视角变化扩展到了第20章的多镜头生成。

## 让人物完成表演

人物参考图可以规定外貌，却很难独自规定一整段动作。若要让人物走近桌子、拿起杯子，再说一句话，就需要进一步给出步伐、手部轨迹、身体姿态和语音。

这些信号之间还存在依赖。手指应当在接触杯子后才带动它移动，说话时的嘴部运动应当与语音对应，人物转身后仍应保持相同身份。把动作迁移到身材不同的人物时，原来的关节位置也未必适合新的身体比例。

第18章讨论如何把姿态、轨迹、相机和接触关系变成控制条件。第21章再加入声音，区分根据已有语音驱动画面、为无声视频生成声音，以及同时生成音视频的方式。若表演来自已有视频，还可以保留原有运动，只修改人物外观或周围环境，这部分将在第22章展开。

## 生成多镜头短片

一段短剧通常由全景、人物近景、反应镜头和动作特写组成。镜头切换允许画面发生突然变化，但观众仍然期待人物、道具和事件保持连续。

例如，人物在全景中把钥匙交给对方，随后切到接钥匙的手，再切到对方的脸。三个镜头需要共享人物身份和钥匙外观，还要共同描述一次交接。若手部特写中钥匙已经被接走，下一镜头却重新出现在交出者手中，单个画面再清楚，事件也无法连贯。

这种任务需要两层组织。镜头内部要生成连续运动；镜头之间要保存主体外观、场景关系与事件状态。第20章会比较联合生成多个镜头和逐镜头生成，解释参考特征、镜头条件与外部记忆如何发挥作用。

对白又会给镜头安排增加时间要求。近景里的人可能正在说话，切到另一人的反应镜头后，声音仍然继续；两人先后发言，也需要把各自的脸、说话时刻和音色对应起来。这些关系不能仅靠给每个镜头分别配一段声音来解决，第21章将从统一的时间安排开始讨论。

## 持续生成一个长镜头

还有一类任务要求画面不断向后延续。相机穿过房间，人物走出画面，又从另一侧回来。系统需要保留已经出现过的内容，同时继续计算新的画面。

整段生成能够让较远的时间位置相互交流，但计算成本会随长度增加。分段生成把每次处理的范围限制在较短窗口内，之后的片段又必须依赖前面已经生成的结果。细小的外观误差可能因此一段段积累，较早的信息也可能因窗口滑动而丢失。

第19章讨论这一矛盾。因果注意力与缓存解决重复计算，Diffusion Forcing 改变不同时间位置的噪声安排，Self Forcing 调整训练时使用的历史，FramePack 则改变历史信息的压缩方式。这些方法各自处理不同环节，需要结合起来理解。

## 本部分的安排

下面各章按照数据、网络、控制和时间组织逐步展开：

| 章节 | 要解释的问题 |
|---|---|
| 第16章 视频表示 | 怎样压缩画面与运动，哪些信息会在编码时损失 |
| 第17章 视频模型 | 网络怎样共同处理时空位置与生成条件 |
| 第18章 运动控制 | 怎样规定关键帧、物体运动、相机与人物动作 |
| 第19章 长视频 | 怎样延续生成、保存历史并减轻误差累积 |
| 第20章 多镜头 | 怎样在视角和场景变化中保持主体与事件连续 |
| 第21章 音视频 | 怎样让声音、口型、动作和镜头共享时间关系 |
| 第22章 视频编辑 | 怎样保留已有内容并修改指定部分 |

阅读时可以始终留意三件事：模型已经获得哪些观测，哪些变化由条件明确给出，还有哪些内容需要根据训练分布估计。它们决定了模型能够控制到什么程度，也有助于解释结果中出现的形变、漂移、错位和衔接问题。
