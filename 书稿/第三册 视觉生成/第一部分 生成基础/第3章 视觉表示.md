# 第 3 章 视觉表示

生成模型可以直接在像素上操作，也可以先把图像写成更短的代码再生成。代码越短，后面的扩散或 Transformer 越省算力；编码器丢掉的细节，解码时却很难凭空补回。

文生图里的 Stable Diffusion 一类系统，去噪发生在自编码器的潜空间，而不是原图像素网格。局部编辑时，若掩码画在像素上，还要问：对应的潜变量格子是否对齐。主体一致性则要求：同一个人的照片编码后，身份相关的方向稳定可复用。

> 透题：下一章会在**像素空间**把扩散机制讲清楚，暂时用不到本章的压缩。压缩的好处，要到潜空间条件生成时才会接上。知识不必按生产线一次装完；这里先建立坐标系。

## 3.1 自编码器与 VAE

### 编码器与解码器

自编码器 \(E\) 把图像映到低维表示 \(z=E(x)\)，解码器 \(D\) 再映回 \(\hat x=D(z)\)。训练最小化重建误差，例如

\[
\mathcal{L}_{\mathrm{rec}}=\|x-\hat x\|_2^2.
\]

若 \(z\) 维数太低，重建糊；若只压重建，不对 \(z\) 加约束，潜空间可能不规则，从随机 \(z\) 解码得不到合理图像。

### VAE

变分自编码器让编码器输出分布 \(q_\phi(z\mid x)\)，并要求它靠近先验 \(p(z)=\mathcal{N}(0,I)\)。目标可以写成重建项与 KL 项之和：

\[
\mathcal{L}_{\mathrm{VAE}}
=
\mathbb{E}_{q_\phi(z\mid x)}\big[-\log p_\theta(x\mid z)\big]
+
\mathrm{KL}\big(q_\phi(z\mid x)\,\|\,p(z)\big).
\]

重参数化使采样 \(z\) 可微。生成时从先验采样再解码；做文生图骨干时，更常见的是只借用 \(E,D\) 当编解码器，真正的生成过程交给扩散或流匹配。

## 3.2 重建与正则化

KL 太强，潜空间很圆，但重建差。KL 太弱，重建好，潜空间可能洞很多，随机采样或插值难看。实际系统会调节 KL 权重，或改用感知损失，对抗损失改善观感（第 2 章）。

对编辑任务，重建质量直接限制不改的区域能不能看起来和原图一样。对一致性任务，正则化影响同一主体的 \(z\) 是否落在可插值的区域。

## 3.3 VQ 与 FSQ

### 向量量化

VQ-VAE 把连续特征打成码本里的离散下标。每个空间位置选一个最近的码字，解码器只看见离散码。这样 \(z\) 变成 token 序列，便于接自回归或掩码模型。

量化不可微，训练常用直通估计：前向用离散码，反向把梯度传给未量化的向量。

### FSQ 等替代

有限标量量化（FSQ）等方案用另一套规则得到离散码，减少码本崩塌等问题。细节因实现而异；共同目的是：得到稳定，可索引的视觉符号，供离散生成模型使用。

## 3.4 VQGAN 与 TiTok

VQGAN 在 VQ 重建之外加入感知损失与对抗损失，提高解码清晰度，并常接 Transformer 做离散先验。TiTok 一类工作进一步追求更短的 token 序列，用更少的符号描述整图，从而降低后续自回归或掩码生成的长度。

它们回答的问题是：图像能不能像句子一样，变成不太长的离散序列。第 8，9 章会回到离散生成；本章只需知道离散表示这条支路存在。

## 3.5 RAE 与 SVG

近年来有工作重新审视潜空间要多正则，多语义。一类思路（如 RAE 相关讨论）强调表示对齐与重建之间的再平衡；另一类（如 SVG 等）关心语义结构是否更适合后续生成。

不必在此绑定某一篇论文的全部符号。需要建立的判断是：

- 潜空间可以偏重建，也可以偏语义  
- 后面的生成器是在这个坐标系里学分布  
- 换编码器，往往要重训或仔细对齐生成器  

文生图换 VAE 却沿用旧的去噪权重，常见现象是颜色发灰或细节错位：不是提示词坏了，是坐标系换了。

## 3.6 压缩与信息损失

设空间压缩倍数为 \(s\)。\(H\times W\) 的图像变成约 \((H/s)\times(W/s)\) 的潜网格。扩散每一步的激活与注意力规模大致按格子数下降，这是潜空间方法能做高分辨率的主要原因。

代价同样明确：

- 细文字，精确边缘，微小道具，可能在编码阶段就丢了  
- 编辑掩码从像素映到潜网格时发生量化，边界可能涨一圈  
- 视频里再加时间压缩，快速动作更容易糊成大致在动  

主体一致性若依赖细纹理（痣，饰品），只靠强压缩潜空间会吃力，往往需要参考图适配或更高保真的编码器。

下一章先在像素网格上把加噪与去噪跑通。等机制清楚了，再把同一套过程搬到本章的 \(z\) 上，就是潜空间扩散的入口。
