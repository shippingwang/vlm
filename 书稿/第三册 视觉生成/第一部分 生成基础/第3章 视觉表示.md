# 第 3 章 视觉表示

图像天然以像素网格的形式存在。像素直观，每一个数值直接对应画面的亮度与色彩。但高清图像的像素总量很大，如果直接在像素网格上搭建生成模型，运算开销会很高。除此之外，像素只是底层色彩信号，本身不自带 “这是人，这是树” 这类高层语义。

生成模型有两种选择：一种直接在像素层面建模；另一种先把图像压缩为更紧凑的抽象表示，也就是潜表示，再在潜表示上建模。本书后面要介绍的扩散，流匹配，两种方式都支持。Stable Diffusion 等主流文生图系统选择第二种路径：生成模型的主体运算放在潜空间，而不是像素空间。最后再通过解码器，把潜表示还原成像素图像。

压缩能够显著降低后续模型的计算量，但压缩是有损操作。编码阶段丢掉的细节，解码器很难凭空复原。做局部编辑时，我们在像素图上画掩码，掩码还要映射到对应的潜网格。想要保持同一个主体在多次生成里不变，它编码之后的潜特征方向，必须稳定一致。

## 3.1 自编码器与 VAE

自编码器是学习图像压缩与重建的基础结构，由编码器 \(E_\phi\) 和解码器 \(D_\theta\) 成对组成。编码器接收原始图像 x，把它映射成潜空间的分布；解码器接收潜变量 z，尝试还原出和原图接近的图像 \(\hat x=D_\theta(z)\)。

最基础的普通自编码器，训练目标只考虑重建误差：

\[
\mathcal{L}_{\mathrm{rec}}=\|x-\hat x\|_2^2
\]

单纯靠像素重建损失会有两个致命缺陷。第一，如果潜变量容量不足，重建图会模糊。第二，**没有对潜分布施加任何约束**。编码器只会拟合训练集图像的映射，不会保证 z 在空间里排布平滑。我们随便采样一个 z，解码出来大概率是无意义噪声，没法用来生成新图。VAE 就是为了解决这个分布约束问题而设计的。

VAE 的核心思路：编码器不再输出一个确定向量 z，而是输出高斯分布的参数，也就是均值 \(\mu_\phi(x)\) 和方差 \(\sigma_\phi(x)\)。由此得到条件分布 \(q_\phi(z\mid x)=\mathcal{N}(\mu_\phi(x),\sigma_\phi^2(x)I)\)。我们希望这个由图像得到的分布，尽可能贴近预先设定的先验分布 \(p(z)=\mathcal{N}(0,I)\)。

我们不能直接从这个分布里采样 z 再回传梯度，采样操作本身是随机的，不可导的。这里引入**重参数化技巧**：先从标准正态分布采样一个独立噪声 \(\epsilon\sim \mathcal{N}(0,I)\)，再用分布参数算出潜变量：

\[
z = \mu_\phi(x) + \sigma_\phi(x)\odot \epsilon
\]

经过这个变换，随机性被转移到独立噪声 \(\epsilon\) 上，\(\mu\) 和 \(\sigma\) 都只是网络输出，整个链路可以正常求导，端到端训练。

VAE 的总损失由两项构成：重建项，加上 KL 散度正则项。

\[
\mathcal{L}_{\mathrm{VAE}} =
\underbrace{\mathbb{E}_{q_\phi(z\mid x)}\big[-\log p_\theta(x\mid z)\big]}_{\text{重建损失}}
+
\underbrace{\mathrm{KL}\big(q_\phi(z\mid x)\,\|\,p(z)\big)}_{\text{KL正则}}
\]

- 重建项：衡量给定 z 时，解码器还原出原图的概率。工程上经常等价于像素 MSE，作用是保证编码，解码之后图像不要失真太多。
- KL 项：约束编码器输出的分布靠近标准正态先验。它强制不同图像对应的潜分布不能到处乱跑，把整个潜空间规整成一个连续，可以采样插值的空间。

这里要区分清楚两个网络的分工：
编码器 \(E_\phi\)：输入图像，输出 \(\mu,\sigma\)，定义后验分布 \(q(z|x)\)。
解码器 \(D_\theta\)：输入潜变量 z，输出图像的分布 \(p(x|z)\)。

放到文生图链路里，VAE 本身**不负责生成创意画面**。它只做像素和潜空间之间双向转换。扩散或者流匹配主干模型，是在这个已经被 VAE 规整好的潜空间里学习样本分布。训练完成之后，推理阶段可以直接从先验 \(p(z)\) 采样 z，送入解码器直接出图；在潜扩散框架里，则是由扩散模型逐步去噪得到 z，再交给 VAE 解码。

## 3.2 重建与正则化的权衡

KL 正则的强度是工程上最重要的权衡点。KL 权重调得很高，潜分布会更规整，采样和插值更稳定，但编码器会被迫丢掉很多图像细节，重建质量下降。KL 权重调低，原图还原更清晰，但潜空间会出现空洞，随机采样，在两个样本之间插值的时候，容易出现崩坏，不合理的画面。

实际开发里，大家会调整 KL 的权重，也经常搭配感知损失，对抗损失，提升解码画面的观感。这个权衡直接影响下游任务。做图像编辑，重建能力决定了没有被修改的区域能不能保持和原图一致；做多图主体一致性，正则的方式决定同一个主体的潜向量，能不能落在平滑，可插值的区域。

## 3.3 离散视觉表示（VQ）

前面 VAE 输出的是连续潜变量。另一类方案是向量量化 VQ，把图像特征映射成码本里的离散序号，整张图转化为一串图像 token。离散 token 天然适配 Transformer，用来做自回归或者掩码图像生成，典型代表是 VQGAN。

这是一套和扩散并行的生成范式。本书主线聚焦连续潜空间上的扩散与流匹配，后续章节不再以离散 token 作为主干。

## 3.4 编码器

不同编码器学到的潜空间完全不一样。一部分编码器优先保证解码后的图像和原图像素接近，看重还原精度；另一部分编码器在训练时更偏向语义对齐，希望同类物体的潜向量自动靠近，方便后续识别，主体编辑。

扩散模型是在这个潜空间上学习分布。一旦编码器换掉，潜空间的数值分布，特征方向全部改变。如果直接沿用原来训练好的扩散权重，模型读不懂新编码器产出的潜向量，结果就是画面偏色，纹理错乱。这也是为什么一套 VAE 需要和对应的扩散模型配对使用。

## 3.5 压缩

编码器会对图像做空间下采样。原图尺寸 \(H\times W\)，编码之后潜网格长宽按固定倍率缩小。后续模型的去噪，注意力计算都在更小的网格上运行，计算量随之下降，这也是潜空间方案能够高效生成高分辨率图的核心原因。

下采样压缩必然会丢失信息，这是底层限制：
细小文字，窄线条，很小的物体，很容易在编码阶段被平均抹平，永久丢失。
编辑时，我们在像素图上绘制的掩码，映射到分辨率更低的潜网格后，边界会变模糊，最后解码回来，编辑接缝容易不自然。
视频模型额外增加时间维度压缩，快速运动的细节更容易被抹掉，出现运动模糊。
