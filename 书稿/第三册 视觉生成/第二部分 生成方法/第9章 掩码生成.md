# 第 9 章 掩码生成

自回归固定扫描顺序。掩码生成不要求从左到右：任意位置都可以在已知上下文下被预测，再按日程逐步揭开。

这更像填空，而不是写长句。MaskGIT，MAR 与离散扩散都落在这条线上。

## 9.1 掩码训练

训练时随机盖住一部分 token，让模型根据可见部分预测被盖住的部分。设可见集合为 \(V\)，掩码集合为 \(M\)，目标常写

\[
\mathcal{L}=\mathbb{E}\Big[
-\sum_{i\in M}\log p_\theta(x_i\mid x_V)
\Big].
\]

与 BERT 式语言掩码同类，只是符号来自视觉码本。掩码率可以固定，也可以按日程从高到低。

## 9.2 MaskGIT

MaskGIT 在推理时从全掩码开始，每轮预测所有未知位置的分布，按置信度保留一部分，其余继续掩码，迭代到全部揭开。

并行预测使单轮能填许多位置，总步数远少于序列长度。置信度启发式决定哪些位置先钉死：钉错了，后续轮难以翻案。

## 9.3 置信度与解码

解码日程规定每轮揭开多少。揭太快，全局未定就钉死局部；揭太慢，又接近逐步扫描的成本。温度与 top-k 影响多样性。

文生图条件经交叉注意力进入时，早期轮若条件弱，布局先漂，后面置信度再高也只是把错构图刻牢。

## 9.4 连续 token 与 MAR

离散码会量化损失。MAR 一类工作对连续（或半连续）的视觉 token 做掩码建模，并用扩散式损失描述被掩位置的条件分布：不是分类到码本，而是在连续向量上回归去噪目标。

这把掩码迭代与扩散损失接在同一骨架上。读论文时分开两件事：哪些位置可见，以及可见条件下如何给未知位置采样。

## 9.5 离散扩散与 D3PM

离散扩散在 token 上定义前向腐蚀（随机改码或改成掩码符），再学反向恢复。D3PM 等给出转移矩阵与训练目标。它与 MaskGIT 的填空日程不同源，但推理都可以看成逐步减不确定度。

与连续扩散比：状态在码本上，似然与采样都带离散结构。与自回归比：不必单方向，却要设计腐蚀与恢复日程。

## 9.6 混合生成

产品系统里常见拼法：

- 自回归或掩码出布局 / 语义 token，再用扩散上细节  
- 统一模型里同一骨干既做理解又做掩码或扩散头（第 15 章）  

选择取决于延迟预算与失败模式：序列模型怕前缀错，扩散怕条件弱，掩码怕过早钉死。编辑时，掩码生成的空间掩码与像素编辑掩码不是同一对象，映射要对齐到 token 格。
