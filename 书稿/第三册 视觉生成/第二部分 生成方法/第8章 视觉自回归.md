# 第 8 章 视觉自回归

扩散把整图当成一条噪声轨迹上的状态。自回归则把图像写成有序序列，每次只预测下一块，条件是已经写下的前缀。

分解方式决定模型每次看见什么，哪些位置能并行，错误又如何沿序列传播。本章从像素与离散 token 的序列化说起，再点到按尺度生成的 VAR 与比特级的 Infinity。

## 8.1 像素自回归

最早的一类模型按光栅顺序预测下一个像素的颜色分布：

\[
p(x)=\prod_{i}p(x_i\mid x_{<i}).
\]

PixelCNN 等用卷积掩码保证因果性。优点是似然可分解；缺点是序列极长，高分辨率几乎不可用，且局部感受野难以一次抓住全局布局。

今天它更多是历史坐标：说明视觉也可以像语言一样因式分解。

## 8.2 离散序列

先把图像编成离散 token（第 3 章的 VQ / FSQ），再对 token 序列做自回归。长度从百万像素降到千级符号，Transformer 才跑得动。

训练是标准的下一 token 预测。生成从 BOS 或从文本条件引出的前缀开始，逐个采样。条件 \(c\) 通常经交叉注意力或前缀 token 注入。

错误会前缀依赖：前几枚 token 布局错了，后面很难救。这与扩散整图迭代修正的行为不同。

## 8.3 VAR

VAR 不按空间光栅扫，而按分辨率从低到高：先生成粗尺度 token，再生成更细尺度，每一尺度条件于更粗的尺度。

直觉接近：先构图，再补纹理。相对纯平坦序列，全局结构往往更稳，细尺度仍可很长。训练与推理都要维护多尺度码本或残差式表示，实现比单尺度 VQ 自回归重。

## 8.4 Infinity

Infinity 一类工作把视觉符号进一步推到比特或更细的二进制表示，并设计相应的预测与并行策略，以兼顾质量与长度。对读者，关键不是背名称，而是：离散序列的粒度可以比 VQ 码字更细，代价与并行方式会跟着变。

## 8.5 条件生成与扩展

文生图：文本进条件，图像 token 自回归写出。局部编辑：可对部分 token 重采样，或把已知区域 token 当强制前缀；边界是否干净，取决于掩码如何映到 token 格。

高分辨率扩展常靠：更短的 tokenizer，多尺度，或与扩散头混用（第 9，15 章）。自回归单独撑到很高分辨率时，延迟与误差累积都刺眼。

与扩散比：自回归一步含义不同——不是噪声水平走一格，而是序列位置走一格。谈少步时，两边的步不可直接换算。
