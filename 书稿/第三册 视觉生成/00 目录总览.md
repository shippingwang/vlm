# 第三册 视觉生成

## 第一部分 生成基础

### 第 1 章 [生成建模](<第一部分 生成基础/第1章 生成建模.md>)

图像生成需要描述许多种可能的结果。同一句话可以对应不同的构图，同一个物体也可以出现在不同的光照下。从二维分布的拟合与采样开始，介绍似然、条件概率和生成目标，再通过归一化流说明可逆变换如何把简单分布变成复杂分布。比较几类生成模型训练时使用的信号，以及生成样本所需的计算。

- 1.1 分布与采样
- 1.2 似然与条件概率
- 1.3 可逆变换
- 1.4 归一化流
- 1.5 生成目标

### 第 2 章 [对抗生成](<第一部分 生成基础/第2章 对抗生成.md>)

逐像素误差难以衡量纹理是否自然。简要介绍生成器与判别器、对抗目标与常见不稳定性，并以 StyleGAN 作为潜空间编辑的历史标本。重点放在今天仍常见的用法：解码器、蒸馏与修复中的感知损失和对抗辅助项，而不把 GAN 当作现行文生图主线。

- 2.1 生成器与判别器
- 2.2 对抗目标
- 2.3 训练稳定性
- 2.4 StyleGAN
- 2.5 感知与对抗损失

### 第 3 章 [视觉表示](<第一部分 生成基础/第3章 视觉表示.md>)

生成模型处理的可以是像素、离散编码，也可以是连续特征。表示越紧凑，生成成本通常越低，但被编码器丢掉的细节也越难恢复。从自编码器和 VAE 出发，介绍离散量化、紧凑 token 与语义潜空间。比较传统 VAE、RAE 和 SVG 的编码与解码过程，分析重建质量、语义结构和生成难度之间的关系。第 4 章先在像素空间讲扩散；压缩与去噪的对接放到潜空间条件生成再回收。

- 3.1 自编码器与 VAE
- 3.2 重建与正则化
- 3.3 VQ 与 FSQ
- 3.4 VQGAN 与 TiTok
- 3.5 RAE 与 SVG
- 3.6 压缩与信息损失

### 第 4 章 [扩散模型](<第一部分 生成基础/第4章 扩散模型.md>)

给图像逐渐加入噪声，轮廓和纹理会慢慢消失。本章在像素空间讲述 DDPM：闭式加噪、反向去噪、去噪损失、时间嵌入与 U-Net，并区分训练一步与生成多步。章末说明高分辨率下为何要把同一套过程搬到第 3 章的潜空间。

- 4.1 前向过程
- 4.2 反向过程
- 4.3 去噪目标
- 4.4 时间嵌入
- 4.5 U-Net
- 4.6 训练与生成

### 第 5 章 [分数与流](<第一部分 生成基础/第5章 分数与流.md>)

噪声预测与带噪分布的对数密度梯度存在联系，由此可以把离散扩散写成连续时间的过程。从分数匹配和 Langevin 采样进入反向 SDE、概率流 ODE，再介绍 Flow Matching 的条件路径与速度回归。区分条件路径和实际采样轨迹，讨论 Rectified Flow、样本耦合与 reflow，并对照 SD3、FLUX 与视频骨干中的速度 / 流匹配目标。

- 5.1 分数匹配
- 5.2 Langevin 采样
- 5.3 SDE 与 ODE
- 5.4 Flow Matching
- 5.5 路径与耦合
- 5.6 Rectified Flow

## 第二部分 生成方法

### 第 6 章 [采样方法](<第二部分 生成方法/第6章 采样方法.md>)

固定模型和初始噪声，改变时间步与更新公式，生成速度和结果仍会变化。从 DDPM、DDIM 进入数值求解，比较随机采样与确定性采样，分析步长、误差和网络调用次数。统一噪声、原图与速度等预测形式，再讨论 EDM、信噪比和日程设计，说明训练目标与推理设置怎样配合。

- 6.1 DDPM 与 DDIM
- 6.2 Euler 与 Heun
- 6.3 DPM-Solver
- 6.4 预测参数化
- 6.5 噪声日程与 EDM
- 6.6 误差与步数

### 第 7 章 [少步生成](<第二部分 生成方法/第7章 少步生成.md>)

较大的步长会积累求解误差，少步模型则通过新的训练目标学习跨越较长的生成区间。分别介绍轨迹蒸馏、一致性训练和分布匹配，再由 MeanFlow 说明平均速度与瞬时速度的区别。比较有教师蒸馏与从头训练两类方法，分析引导、样本多样性和编辑能力在少步生成中的变化。

- 7.1 渐进蒸馏
- 7.2 一致性模型
- 7.3 潜空间一致性
- 7.4 分布匹配蒸馏
- 7.5 MeanFlow
- 7.6 引导与质量

### 第 8 章 [视觉自回归](<第二部分 生成方法/第8章 视觉自回归.md>)

图像的联合概率可以按像素、token 或尺度分解，分解方式决定了模型每次预测什么，以及哪些位置能够并行生成。从 PixelCNN 和离散视觉序列进入 VAR，推导逐尺度预测，再介绍 Infinity 的比特表示与预测方式。结合文本条件和高分辨率生成，分析表示、生成顺序和计算成本。

- 8.1 像素自回归
- 8.2 离散序列
- 8.3 VAR
- 8.4 Infinity
- 8.5 条件生成与扩展

### 第 9 章 [掩码生成](<第二部分 生成方法/第9章 掩码生成.md>)

固定的扫描顺序并非生成图像的唯一选择。掩码模型根据已知位置预测未知位置，再按一定规则逐轮补全。从 MaskGIT 介绍掩码训练、置信度和解码日程，随后进入 MAR，用扩散损失描述连续 token 的条件分布。区分自回归依赖、掩码迭代与离散扩散，分析序列模型和扩散模型的组合方式。

- 9.1 掩码训练
- 9.2 MaskGIT
- 9.3 置信度与解码
- 9.4 连续 token 与 MAR
- 9.5 离散扩散与 D3PM
- 9.6 混合生成

## 第三部分 图像生成

### 第 10 章 [条件生成](<第三部分 图像生成/第10章 条件生成.md>)

文字、类别和图像参考都会改变模型应当采样的分布。沿着文本编码与交叉注意力追踪条件信息，推导分类器引导和分类器自由引导，分析条件丢弃、负面条件及引导强度。随后把生成过程放入潜空间，以 Stable Diffusion 连接编码器、去噪网络和解码器，讨论数量、关系与文字渲染中的失败。

### 第 12 章 [像素生成](<第三部分 图像生成/第12章 像素生成.md>)

潜空间压缩降低了计算成本，也给细节重建设下限制。直接生成像素可以绕过独立的压缩编码器，却需要处理更高维的输入与输出。结合 JiT 和 PixelDiT，讨论原图预测、patch 大小、网络瓶颈和分层计算，比较像素生成与 RAE 等潜空间方法在训练、细节和扩展方面的取舍。

修改图像时，需要同时规定改变什么和保留什么。从加噪后重新生成进入局部重绘、扩图与反演，分析重建误差如何影响编辑。再介绍注意力控制、指令编辑和结构条件，比较边缘、深度、分割与姿态的约束方式，讨论多条件冲突和编辑区域之外的变化。

同一个人物换了姿态和背景，仍应保留身份特征；参考图中的服装、光照却未必都应照搬。比较 IP-Adapter 等参考条件与 Textual Inversion、DreamBooth、LoRA 等参数适配方法，分析身份、风格和背景的纠缠。进一步讨论多主体绑定、局部特征与适配权重组合，为跨帧和跨镜头保持主体准备条件表示。
