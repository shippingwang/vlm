# 现代视觉语言模型

**面向读者**：有深度学习基础；读过或并行读《现代大模型》第一册里的注意力、因果掩码、KV Cache、RoPE 更省事

**读完能做到**：说清主流 VLM 架构与三阶段训练；讲清 CLIP / SigLIP / DINO 各解决什么、短板在哪；说清 NTP 在图文序列上怎么算、视觉侧算不算；看懂 grounding 与 DeepSeek-VL 一类配方在改哪块接口

本书慢慢讲、讲全；已经沉淀的机制优先，不堆发布会。姊妹书覆盖的 Transformer / KV / RoPE 不重写，只接二维与视觉 token 后果。

## 目录

- **序章 案例：看图办事**：识图问答、文档/表格、GUI 点选——各多出什么 token、什么协议

### 第一部分 坐标系与骨架

- **第 0 章 预备与边界**：从 LLM 带走什么；VLM 新增问题清单；记号（图像、patch、视觉 token、连接器）
- **第 1 章 VLM 在做什么**：描述、VQA、grounding、OCR/文档、多图、工具与 Agent；能力不是同一个损失能盖住的
- **第 2 章 架构总览**：`视觉塔 → 连接器 → 语言模型`；双塔检索式；早期融合 / 原生多模态；冻结课表
- **第 3 章 数据流走读**：一张图从像素到 logits；Prefill 里视觉前缀与文本后缀如何接

### 第二部分 视觉表示：眼睛从哪来

- **第 4 章 ViT 回顾**：patch embedding、编码器栈；分辨率 / patch / 步长如何决定 token 数
- **第 5 章 CLIP**：对比学习在做什么；训练与推理用法；**优点与缺点**（开放词汇强、细粒度/定位/OCR 弱、分辨率墙）
- **第 6 章 SigLIP 与对比损失变体**：sigmoid 对比 vs softmax；扩展性；进 VLM 时为什么常换 SigLIP 塔
- **第 7 章 DINO / DINOv2**：自蒸馏在做什么；教师—学生、多裁剪；与对比眼睛的差别；当 VLM 视觉塔时的利弊
- **第 8 章 视觉塔选型**：CLIP 系 vs DINO 系 vs 混合；要不要解冻视觉塔；和下游任务的匹配

### 第三部分 分辨率、token、融合

- **第 9 章 动态分辨率与切图**：固定 resize 的代价；AnyRes / 动态切图；顺序与特殊 token；训练—服务同协议
- **第 10 章 视觉 token 预算**：手算张数；压缩 / 合并 / 剪枝；对上下文与 KV 的账（细表附录 C）
- **第 11 章 连接器**：MLP；Q-Former / 可学习 query；感知器式压缩；主职是对齐空间并控 token 数
- **第 12 章 序列拼装与模板**：图文交错；占位符与 chat template；多图；纯文本 replay
- **第 13 章 位置表示**：一维 RoPE 套 patch 的问题；2D RoPE；视频时间维

### 第四部分 能力专题

- **第 14 章 Grounding 怎么做**：框 / 点 / 多边形如何变成可生成的 token；数据与损失；和检测器 / DINO 定位能力的关系；常见失败模式
- **第 15 章 OCR 与文档**：高分辨率、阅读顺序、表格与版面；和切图策略如何绑在一起
- **第 16 章 GUI 与 Computer Use**：截图观察、动作空间、坐标映射；和 grounding 的差别

### 第五部分 训练目标与三阶段

- **第 17 章 NTP loss**：next-token prediction 在图文序列上的定义；**视觉 token 位置算不算 NTP**（通常：视觉段是条件前缀，损失落在文本 token；例外与变体一并写清）
- **第 18 章 三阶段训练总览**：对齐 → 指令微调 → 偏好/RL；每阶段冻谁、训谁、数据长什么样、成功标准
- **第 19 章 阶段一：对齐预训练**：先训连接器；图文对与过滤；分辨率课表
- **第 20 章 阶段二：多模态指令微调**：任务混搭与配比；纯文本 replay；预处理不一致的失败模式
- **第 21 章 阶段三：偏好与强化学习**：多模态偏好；过程监督；GUI 环境里的奖励

### 第六部分 推理与评测

- **第 22 章 Prefill 里的视觉 token**：图像一次进 Prefill；与 Decode 不对称；batch 长度抖动
- **第 23 章 服务与缓存**：切图与编码器在哪一层；视觉特征缓存；和 KV / 前缀缓存分账
- **第 24 章 评测**：VQA / 文档 / OCR / grounding / 综合榜；泄漏与语言先验刷分

### 第七部分 案例与前沿

- **第 25 章 DeepSeek-VL / VL2**：骨架与视觉侧选型；训练阶段；和 LLaVA 式基线差在哪
- **第 26 章 视频与长序列图文**：帧采样；时空 token；接长上下文稀疏 / 状态路线
- **第 27 章 原生多模态与统一生成**：理解与生成是否同一套自回归；和「塔+连接器」对照
- **结语**：回看序章；架构 / 数据 / 服务清单上还缺什么
