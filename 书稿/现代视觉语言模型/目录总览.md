# 现代视觉语言模型

**面向读者**：有深度学习基础；《现代大模型》第一册里的注意力、KV Cache、RoPE、Prefill/Decode 视为已知

**读完能做到**：说清多模态任务与模型边界；讲清 VLM 核心模块与两类主流架构；写清 NTP、辅助损失与经典三阶段训练；后训练如何注入定位与文档能力；推理与评测陷阱；视频、统一模型与 Agent 的接口增量

覆盖求全、机制写细。CLIP、SigLIP、DINO、DeepSeek-VL、Qwen2.5-VL 等出现在相关节里，不单独占章。

与姊妹书：语言模型机制归《现代大模型》；本书写视觉—语言增量。
