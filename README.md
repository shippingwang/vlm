# 现代视觉语言模型

仓库：<https://github.com/shippingwang/vlm>

一册讲清 VLM：视觉表示（CLIP / SigLIP / DINO）、架构与数据流、token 与连接器、grounding、NTP 与三阶段训练、推理评测、DeepSeek-VL 等案例。

语言模型侧的注意力、KV Cache、RoPE、Prefill/Decode 以姊妹书 [《现代大模型》](https://github.com/shippingwang/llm) 为前置，本书不重写 Transformer 正文。
