# 现代视觉语言模型

仓库：<https://github.com/shippingwang/vlm>

一册讲视觉—语言模型：视觉表示（CLIP / SigLIP / DINO）、模型结构、定位与文档、训练（含 NTP 与三阶段）、推理评测，以及 DeepSeek-VL 等案例。

分章顺序参考 Caltech [CS148](https://georgiagkioxari.com/teaching/cs148/)、Georgia Tech [CS8803-VLM](https://faculty.cc.gatech.edu/~zk15/teaching/AY2026_cs8803vlm_fall/)、CMU [11-777](https://multicomp.cs.cmu.edu/mmml-course/fall2026/schedule/) 的常见组织，并按工程需要补上推理与训练阶段。

语言模型侧机制以姊妹书 [《现代大模型》](https://github.com/shippingwang/llm) 为前置。
